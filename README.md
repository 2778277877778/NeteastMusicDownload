# NeteastMusicDownload
网易云音乐工具箱 · V2.0 Windows 免安装便携版：在线下载 与 本地 .ncm 解码 两页共用一个音乐库目录。 自带 Python 运行时，整个文件夹拷走就能用。 仅供个人学习与技术研究。音乐、封面、歌词的版权归权利人，请遵守网易云服务条款与当地法规，不要传播下载的文件。 功能 在线下载 — 多行混合粘贴（单曲 / 专辑 / 歌单 / 歌手 / 电台 / 播客），一次解析成队列；两层去重； 纯单曲走批量接口（一次 200 首）；8 档音质含杜比全景声，取不到会自动降级并说明； 写 ID3v2.3 / Vorbis Comment + 封面 + 内嵌歌词；断点续传；只重试失败项；取消不留半成品； 支持拖入 .txt 链接清单或 .ncm。
