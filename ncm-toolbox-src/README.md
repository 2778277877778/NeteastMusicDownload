# 网易云音乐工具箱 · V3.0

Windows 免安装便携版：**在线下载** 与 **本地 `.ncm` 解码** 两页共用一个音乐库目录。
自带 Python 运行时，整个文件夹拷走就能用。

> 仅供个人学习与技术研究。音乐、封面、歌词的版权归权利人，请遵守网易云服务条款与当地法规，**不要传播下载的文件**。

## 功能

**在线下载** — 多行混合粘贴（单曲 / 专辑 / 歌单 / 歌手 / 电台 / 播客），一次解析成队列；两层去重；
纯单曲走批量接口（一次 200 首）；8 档音质含杜比全景声，取不到会自动降级并说明；
写 ID3v2.3 / Vorbis Comment + 封面 + 内嵌歌词；断点续传；只重试失败项；取消不留半成品；
支持拖入 `.txt` 链接清单或 `.ncm`。

**NCM 解码** — **解密已内置**（纯 Python，无任何外部程序）：把 `.ncm` 还原成容器里的原始
mp3 / flac，写入封面与标签，可带上同目录的歌词。并发 1–8、重复内容自动跳过、
各写各的临时目录后原子移入音乐库、中途取消不留半成品。

> 只解容器，**不做转码**：输出格式就是当初下载到的格式。要转成 m4a / opus 或改码率，
> 请交给任意转码工具处理。

## 快速开始

1. **完整解压**（`python\` 是内置运行时，别拆散）→ 双击 **`网易云音乐工具箱.exe`**。
   看不到窗口或有报错时用 `启动-调试.bat`（保留控制台），或 `网易云音乐工具箱.exe --debug`。
2. 首次用点 **「设置…」→「网页登录取 Cookie」** 登录一次，之后自动记住。
3. 选好音乐库目录 → 粘贴链接 → `解析列表` → `开始下载`。需要 Windows 10 / 11 64 位。

## 登录（付费曲目 / 无损必须）

不带登录态时付费曲目返回 `code -110`，免费曲目最高只有 128k。

- **网页登录（推荐）** —— 程序自己启动一个带调试端口的独立浏览器配置，登录后自动回填，长期有效。
- **读本机浏览器** —— 启动时自动尝试。但 **Edge 运行时会独占锁定 Cookie 数据库**，读不了就完全退出浏览器（托盘也要退）再试，或改用上面那种。
- **手动填 Cookie** —— F12 → Application → Cookies → `music.163.com` → 复制 `MUSIC_U` 的值。
  它是 HttpOnly，控制台里 `document.cookie` 看不到。
- **扫码登录目前大概率失败** —— 风控返回 `8821`，手机上显示授权成功但服务端不给登录态。窗口会明确提示。

点「验证」会真的去取一次流，直接告你能不能下付费曲目。

> **Cookie 等同账号凭证。** 只取 `163.com` 的 4 个登录字段，复制一份再解、不写回浏览器；
> 明文存在本机 `%USERPROFILE%\.ncm\gui.json` —— 别把这个文件发给任何人。

## 常见问题

- **双击 exe 没反应** —— 先确认是**完整解压后**的文件夹（单独把 exe 拷出去一定失败，它要找同目录的
  `python\` 和 `ncm_gui.py`）。缺文件时它会弹框说明，不会静默失败。程序自身的异常写在
  `%USERPROFILE%\.ncm\gui.log`。首次运行若 SmartScreen 拦"未知发布者"，点「更多信息 → 仍要运行」。
- **`.bat` 用不了** —— 两个批处理保留作为兜底。别用会把行尾改成 LF 的编辑器保存它们：cmd 读 LF-only
  批处理会吃掉行首字符，表现就是"双击没反应"。
- **杀软报警** —— 打包的 Python 常见误报。只访问 `music.163.com` 和本机 `127.0.0.1`（自动登录用的调试端口）。
- **"下载成功"却只有几十字节** —— 上游硬编码的 `Host` 头会让 CDN 回一段 43 字节错误 JSON；V3.0 已修，
  并在响应不是音频时直接报错，不会再静默产出垃圾文件。
- **换电脑要重新登录** —— 配置存在 `%USERPROFILE%\.ncm\`，与程序目录分开。

完整实现细节与踩坑记录见同目录的 **`GUI说明.md`**，免安装要点版见 **`使用说明.txt`**。

## 明确不做

刷歌 / 每日任务、手机号短信登录（上游同类项目自述"封号风险极高"）；灰歌解锁（那是绕过授权，不是取长补短）；
CookieCloud 同步（扩大凭证暴露面）。

## V3.0（2026-10-07）

- **可移植性** 清掉内置运行时里的 editable 残留（会把 `ncm` 指向开发机路径）、去掉个人绝对路径、开发脚本移出包。
- **界面** 新增 `gui_theme.py` 视觉层，深浅配色按系统底色自动切换；修复状态栏被 pack 挤成 0 高（音乐库 / 音质 / 登录状态此前根本不显示）；输入区加占位引导、粘贴与搜索分行；次要文字对比度 3.5:1 → 9:1。
- **性能** 日志批量上屏（3000 行 2.9s → 5ms）、重依赖延迟导入（启动 0.67s → 0.36s）、空闲轮询降频。
- **NCM 解码内置化** 去掉对外部 `NCMDecoder.exe` 的依赖（纯 Python 解密，算法照搬
  `taurusxin/ncmdump`，MIT），并处理了网易云那种 `.lrc` 里混 JSON 行的歌词。
- **文档** 新增本 README，其余文档与实际文件名 / 模块清单对齐。
