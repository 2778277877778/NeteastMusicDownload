网易云音乐工具箱 —— 免安装便携版
================================================

【怎么用】
  双击「网易云音乐工具箱.exe」即可。不需要安装 Python 或任何依赖。
  出问题时用「启动-调试.bat」（或 网易云音乐工具箱.exe --debug），会保留控制台显示报错。
  首次运行若被 SmartScreen 拦下（未签名发布者），点「更多信息 → 仍要运行」。
  「启动.bat」仍在，作为兜底入口。


【重要：这个文件夹必须完整】
  里面包含一个精简的 Python 运行时（python\ 目录，约 60 MB）。
  打包/拷贝时请把整个文件夹一起带走，不要把文件拆散。


【第一次使用要登录】
  程序启动后会尝试自动获取登录态。如果没有，点「设置…」→
  用「网页登录取 Cookie」登录一次，之后会自动记住。
  登录态存在 %USERPROFILE%\.ncm\browser_profile 里，
  和这个程序文件夹是分开的 —— 也就是说换电脑需要重新登录一次。


【下载的音乐存哪】
  默认目录在「设置…」→「下载」里配置。
  下载时会自动写入封面和歌词（内嵌在音频文件里，不产生额外文件）。


【NCM 解码是内置的】
  解密算法已用 Python 实现在包里（ncm_dump.py），不需要任何外部程序。
  输出为容器内的原始格式（mp3 / flac），只解容器不转码；
  要转 m4a / opus 或改码率，请另外用转码工具。


【目录说明】
  README.md           项目说明（功能、用法、常见问题、许可、版本）
  网易云音乐工具箱.exe  启动器（约 100 KB 原生壳，拉起内置 python\pythonw.exe）
  launcher.c          启动器源码，见 GUI说明.md 的构建命令
  启动.bat            兜底启动（无控制台窗口）
  启动-调试.bat        调试启动（保留报错信息）
  ncm_gui.py           主程序
  gui_common.py        设置持久化、链接解析、标签写入
  gui_download.py      在线下载页
  gui_decode.py        NCM 解码页
  ncm_dump.py          NCM 容器解密（算法照搬 taurusxin/ncmdump，MIT）
  gui_cookie.py        从本机浏览器取 163.com 登录 Cookie
  gui_login.py         网页登录 / 扫码登录对话框
  gui_settings.py      「设置…」对话框
  gui_theme.py         界面外观（深/浅两套配色，跟随系统）
  ncm\                 网易云接口封装（上游 codezjx/netease-cloud-music-dl）
  python\              内置 Python 3.12 运行时 + 依赖，别删
  GUI说明.md           完整功能说明与实现细节
  LICENSE.txt          许可与署名（上游 MIT 原文 + 自研部分 MIT）


【它会读取本机浏览器的网易云登录状态】
  启动时会自动去本机浏览器里找 music.163.com 的登录 Cookie，这样付费曲目不用
  每次手动粘。范围是收紧的：只挑 163.com 域名、只取 4 个登录相关字段，
  做法是把 Cookie 数据库复制一份再解，不会改动浏览器里的原始文件。
  解出的 MUSIC_U 等同账号凭证，明文存在 %USERPROFILE%\.ncm\gui.json，
  别把这个文件发给别人。不想用这个功能就在「设置…」里清空 Cookie。


【如果杀毒软件报警】
  这是 Python 程序被打包的常见误报。程序不联网到任何第三方服务器，
  只访问 music.163.com。不确定可以先用「启动-调试.bat」看它做了什么。


【环境要求】
  Windows 10 / 11 64 位。
